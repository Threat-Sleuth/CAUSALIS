# Overview

**CAUSALIS** is a framework for **Controlled Cyber Experimentation**
designed for reproducible cybersecurity research.

## Key capabilities

-   Controlled traffic generation
-   Attack orchestration
-   Evidence collection
-   Dataset generation
-   Feature extraction
-   Machine Learning evaluation
-   HTML reporting
-   Reproducible experimentation

------------------------------------------------------------------------

# Features

-   Modern Flask interface
-   Campaign management
-   Automated datasets
-   Binary & multiclass ML
-   SQLite backend
-   HTML reports
-   Modular architecture
-   Designed for research

# Quick Start

``` bash
git clone https://github.com/<your-user>/causalis.git
cd causalis

python -m venv .venv

# Linux
source .venv/bin/activate

# Windows
.venv\Scripts\activate

pip install -r requirements.txt

python run.py
```
